## Планировщик задач
### Описание
Планировщик задач нужен для того удобно сохранять напоминания о запланированных задачах с возможностью устанавливать правила для повторяющихся задач, например посещений тренажерного зала или оплата комунальных счетов. Он позволяет добавлять задачи в список, указывая название задачи, комментарий, дату выполнения, опциональное правило для повторения задачи в заданном формате, редактировать задачи, удалять и запрашивать их по одиночке либо списком, отсортированным по дате

#### Формат правила для повторения задачи 
- [d <число>] **выполнение задачи каждые n дней**
- [y] **выполнение задачи ежегодно**
- [w <через запятую от 1 до 7>] **задача назначается в указанные дни недели, где 1 — понедельник, 7 — воскресенье.**
- [m <через запятую от 1 до 31, -1, -2> [через запятую от 1 до 12]] **задача назначается в указанные дни месяца, -1 означает последний день месяца, -2 предпоследний день месяца При этом вторая последовательность чисел опциональна и указывает на определённые месяцы.**

### Список выполненных заданий со звёздочкой.
* Реализована возможность определять путь к файлу базы данных через переменную окружения `TODO_DBFILE` и порт через переменную окружения `TODO_PORT`
* Реализована поддержка правил повторения для еженедельных и ежемесячных задач
* Реализован поиск задач по дате или содержанию с помощью строки поиска
* Реализована аутентификация с использованием пароля, задаваемого через переменную окружения `TODO_PASSWORD` и вводимого на странице входа. Дальнейшая верификация API запросов осуществляется с помощью временного JWT токена, который подписывается контрольной суммой, вычисленной алгоритмом SHA256 от пароля.
* Реализована поддержка запуска приложения в docker контейнере

### Инструкция по запуску кода локально

#### Требования
- Go 1.24.0 или выше

#### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Cornpop456/scheduler_go_final_project.git
   cd scheduler_go_final_project
   ```
2. **Перейдите в ветку `develop`**
   ```bash
   git checkout develop
   ```

3. **Установите зависимости:**
   ```bash
   go mod download
   ```

4. **Запустите сервер:**
   ```bash
   go run main.go
   ```
   **Или соберите и запустите бинарный файл:**
   ```
   go build -o server . && ./server
   ```

5. **Откройте браузер и перейдите по адресу:**
   ```bash
   http://localhost:7540
   ```

#### Настройки через переменные окружения

Вы можете настроить приложение через переменные окружения:

- **TODO_DBFILE** - путь к файлу базы данных SQLite (по умолчанию: `scheduler.db`)
- **TODO_PORT** - порт для запуска сервера (по умолчанию: `7540`)
- **TODO_PASSWORD** - пароль для доступа к сайту. Если установлен, сайт будет открываться на странице с вводом пароля

**Пример запуска с настройками:**
```bash
TODO_DBFILE=./data/tasks.db TODO_PORT=8080 TODO_PASSWORD=mypassword go run main.go
```

### Инструкция для сбоки и запуска в docker контейнере 

1. **Соберите исполняемый файл:**
   ```bash
   go build -o scheduler . 
   ```
2. **Соберите docker образ**
   ```bash
   docker build -t scheduler_app . && rm ./scheduler
   ```

3. **Запустите контейнер, указав папку, где будет хранится база данных sqlite и при необходимости переопределив переменные окружения**
   ```bash
   docker run -v <ваш путь к папке>:/data -p 7540:7540 scheduler_app
   ```
   ## ⚙️ Опции запуска

- `-v <путь к папке>:/data` — монтирует локальную папку для хранения файла SQLite.
- `-p 7540:7540` — пробрасывает порт 7540 из контейнера на хост.

**По умолчанию внутри контейнера используются переменные окружения:**

- `TODO_DBFILE` — путь к файлу базы данных (по умолчанию `/data/scheduler.db`).
- `TODO_PORT` — порт сервера (по умолчанию `7540`).
- `TODO_PASSWORD` — пароль (по умолчанию `1234`).

Вы можете переопределить эти параметры при запуске:

```bash
docker run \
  -v ./sqlite-data:/data \
  -p 9090:9090 \
  -e TODO_DBFILE=/data/custom.db \
  -e TODO_PORT=9090 \
  -e TODO_PASSWORD=supersecret \
  scheduler_app
