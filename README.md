## Планировщик задач
### Описание
Планировщик задач нужен для того удобно сохранять напоминания о запланированных задачах с возможностью устанавливать правила для повторяющихся задач, например посещений тренажерного зала или оплата комунальных счетов. Он позволяет добавлять задачи в список, указывая название задачи, комментарий, дату выполнения, опциональное правило для повторения задачи в заданном формате, редактировать задачи, удалять и запрашивать их по одиночке либо списком, отсортированным по дате

#### Формат правила для повторения задачи 
- [d <число>] **выполнение задачи каждые n дней**
- [y] **выполнение задачи ежегодно**
- [w <через запятую от 1 до 7>] **задача назначается в указанные дни недели, где 1 — понедельник, 7 — воскресенье.**
- [m <через запятую от 1 до 31, -1, -2> [через запятую от 1 до 12]] **задача назначается в указанные дни месяца, -1 означает последний день месяца, -2 предпоследний день месяца При этом вторая последовательность чисел опциональна и указывает на определённые месяцы.**

### Инструкция по запуску кода локально

#### Требования
- Go 1.24.0 или выше

#### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Cornpop456/scheduler_go_final_project.git
   cd scheduler_go_final_project
   ```

2. **Установите зависимости:**
   ```bash
   go mod download
   ```

3. **Запустите сервер:**
   ```bash
   go run main.go
   ```
   **Или соберите и запустите бинарный файл:**
   ```
   go build -o server . && ./server
   ```

4. **Откройте браузер и перейдите по адресу:**
   ```bash
   http://localhost:7540
   ```

#### Настройки через переменные окружения

Вы можете настроить приложение через переменные окружения:

- **TODO_DBFILE** - путь к файлу базы данных SQLite (по умолчанию: `scheduler.db`)
- **TODO_PORT** - порт для запуска сервера (по умолчанию: `7540`)

**Пример запуска с настройками:**
```bash
TODO_DBFILE=./data/tasks.db TODO_PORT=8080 go run main.go
```
